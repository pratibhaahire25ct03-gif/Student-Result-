Student Result Management System

This is a Python-based Student Result Management System developed to manage and calculate student results easily. It stores student details and marks in a CSV file using Python file handling.

The system can:
- Add student details and marks
- Calculate total marks
- Calculate percentage and grade
- Display PASS/FAIL result
- Store the result in a CSV sheet
- View all previous results
- Search result by roll number

Technologies Used: Python, CSV File Handling
